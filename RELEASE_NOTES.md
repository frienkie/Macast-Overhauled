# Macast-Overhauled v0.8 for macOS

This fork keeps Macast usable on current Apple Silicon Macs. The application is still named **Macast.app**.

- Bundles MPV and the supported plugins, including Bilibili casting support.
- Refreshes the player controls with aligned subtitles and danmaku buttons and display-aware sizing.
- Improves video switching and removes the obsolete in-app update check. Download future releases from this repository.
- Includes English and Chinese guides plus third-party license notices.

Download the DMG, open it, and drag **Macast.app** into **Applications**. The app is ad hoc signed and is not Apple notarized, so macOS may ask you to use **Control-click → Open** the first time. This release is for **Apple Silicon (arm64)**.

Playback and casting need real-device testing; please report issues with the sender app, macOS version, and a short description of what happened.
